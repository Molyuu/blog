为什么我要自己写一个视频播放器

2026-11-20 · [技术] · 约 2400 字 · 改过 2 次

手机里存了一堆从电脑拷过来的视频，大部分是电影，少数是课程录像。试过 VLC、Infuse、Outplayer，每个都能用，每个都有一点让我别扭的地方：有的界面太满，有的要订阅，有的字幕设置藏得很深。

于是我想：要不自己写一个？只做三件事——打开本地文件、记住看到哪里、字幕能调大小。别的都不要。

一、先跑起来

最小的版本其实很短。AVPlayer 本身已经做好了解码和播放，我要做的只是把文件 URL 交给它：

let player = AVPlayer(url: fileURL)
let controller = AVPlayerViewController()
controller.player = player
present(controller, animated: true) {
    player.play()
}

真正麻烦的是后面：沙盒里的文件怎么导入、MKV 格式系统不认怎么办、进度存在哪里。这些我会一个一个写。

写给自己用的软件，最大的好处是可以不讲道理。

二、为什么不直接用现成的

老实说，理性上没有理由。现成的 App 比我写的好一百倍。但我想知道一个视频从文件变成画面，中间到底经过了什么。这是另一种「看电影」。
